# Olist E-Commerce Analytics

## Project Overview
An e-commerce analytics project using SQL and Excel to explore sales performance, product categories, customer purchasing behavior, and data quality.

## Tools Used
- MySQL and SQL
- Excel
- Data validation and reconciliation
- RFM (Recency, Frequency, Monetary) customer segmentation

## Key Analysis
- Validated source tables, row counts, order IDs, and order statuses.
- Analyzed sales revenue, freight, and monthly sales trends.
- Segmented customers using RFM analysis.
- Identified revenue by product category.
- Validated product joins and investigated unmatched product records.
- Reconciled category revenue against delivered-order revenue.

## Project Files
- `01_data_validation.sql` — Data validation
- `02_sales_analysis.sql` — Sales and monthly trends
- `03_customer_rfm_analysis.sql` — Customer segmentation
- `04_category_analysis.sql` — Category revenue
- `05_final_validation.sql` — Final validation
- `06_product_join_validation.sql` — Product join checks
- `07_unmatched_product_validation.sql` — Unmatched product checks
- `08_category_revenue_reconciliation.sql` — Revenue reconciliation
- `Olist_Ecommerce_Analytics.xlsx` — Excel analytics workbook

## Objective
To turn e-commerce transaction data into useful business insights and demonstrate practical data analysis skills.

*Note: Analysis is based on the available Olist dataset and the filters defined in the SQL scripts.*
